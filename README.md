# BloggingApplication

Static front-end (HTML/CSS) for a simple blogging site, built as a case study in the IIITB Post Graduate Diploma program.

## What's here
- `index.html` – landing page
- `html/bloglist.html` – list of blog posts
- `html/post.html` – single post view
- `font-awesome-4.7.0/` – vendored icon library

## Tech stack
HTML5, CSS, Font Awesome 4.7. No backend or build step.

## How to run
Open `index.html` in a browser, or serve the folder:
```bash
python3 -m http.server 8000   # then visit http://localhost:8000
```

## Key concepts
Semantic page layout, CSS styling, multi-page static navigation.
